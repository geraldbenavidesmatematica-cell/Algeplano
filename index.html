Banco de piezas

Pulsa una pieza para añadirla al tablero. Puedes añadir tantas copias como necesites.
Cómo utilizarlo

1. Elige una pieza del banco.

2. Arrástrala sobre la cuadrícula. Las piezas se ajustan a las líneas.

Usa Lápiz para escribir o dibujar sobre la cuadrícula y Borrador para borrar trazos. Regresa a Mover piezas para manipularlas.

3. Selecciona un rectángulo y pulsa Rotar 90° o la tecla R.

4. Usa Supr para eliminar y Ctrl+D para duplicar.

Medidas convencionales: x² = 4×4 celdas, x = 4×1 y 1 = 1×1. Cada celda representa una unidad gráfica; el valor algebraico sigue siendo simbólico.
